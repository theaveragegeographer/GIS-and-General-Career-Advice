# Chapter 7: Resume and Cover Letter Tips

## Introduction

Your resume and cover letter are often your first impression with potential employers. In a competitive job market, these documents need to clearly communicate your value and capture attention quickly. This chapter provides strategies for creating compelling application materials that get you noticed.

## Resume Fundamentals

### General Guidelines

**Length**:
- **Entry-Level**: 1 page maximum
- **Mid-Career**: 1-2 pages
- **Senior/Executive**: 2 pages acceptable

**Format**:
- Clear, professional font (Arial, Calibri, Times New Roman)
- 10-12 point font size
- Consistent formatting throughout
- Adequate white space
- Easy to scan quickly
- PDF format for submission (preserves formatting)

**Sections to Include**:
1. Contact Information
2. Professional Summary or Objective
3. Skills
4. Experience
5. Education
6. Certifications (if applicable)
7. Optional: Projects, Publications, Awards

### Contact Information

**Include**:
- Full name
- Phone number
- Professional email address
- LinkedIn profile URL
- Portfolio website/GitHub (if relevant)
- City and state (full address no longer necessary)

**Avoid**:
- Unprofessional email addresses
- Multiple phone numbers
- Personal social media (unless professional)

### Professional Summary

A brief 2-4 sentence overview highlighting your value proposition.

**Entry-Level Example**:
"Recent Geography graduate with specialization in GIS and remote sensing. Proficient in ArcGIS Pro, Python, and spatial analysis. Completed capstone project analyzing urban heat island effects using Landsat imagery. Seeking entry-level GIS Analyst position to apply technical skills and contribute to environmental planning initiatives."

**Mid-Career Example**:
"GIS Analyst with 5+ years of experience in environmental consulting. Expert in spatial analysis, Python automation, and geodatabase management. Led GIS component of 15+ environmental impact assessments. Strong communication skills with ability to present complex spatial information to non-technical stakeholders."

**Alternative: Objective Statement** (for career changers):
"Software developer transitioning to GIS, bringing 3 years of Python programming experience and passion for spatial problem-solving. Recently completed GIS Certificate program and seeking opportunities to apply technical skills in geospatial domain."

### Skills Section

**Format Options**:
- **Category-based**: Group related skills
- **Proficiency-based**: Expert, Proficient, Familiar
- **Simple list**: Straightforward enumeration

**Example (Category-based)**:
```
GIS Software: ArcGIS Pro, ArcGIS Online, QGIS
Programming: Python (ArcPy, GeoPandas), SQL, JavaScript
Analysis: Spatial statistics, network analysis, suitability modeling
Cartography: Map design, web mapping, data visualization
Data: Geodatabase design, data quality, metadata
```

**Tips**:
- Include only skills you can discuss confidently
- Use keywords from job description
- Be honest about proficiency levels
- Update regularly as you learn new skills
- Include soft skills (communication, teamwork, problem-solving)

### Experience Section

**Format for Each Position**:
```
Job Title
Company Name, Location
Dates (Month Year - Month Year)
• Bullet point describing responsibility or achievement
• Bullet point describing responsibility or achievement
• Bullet point describing responsibility or achievement
```

**Writing Effective Bullets**:

**Use Action Verbs**:
- Analyzed, Created, Developed, Implemented
- Managed, Designed, Automated, Optimized
- Collaborated, Presented, Coordinated, Led

**Quantify Achievements**:
- Poor: "Created maps for projects"
- Good: "Created 50+ maps for 12 environmental assessment projects"

- Poor: "Improved processing time"
- Good: "Reduced data processing time by 40% through Python automation"

**Show Impact**:
- Poor: "Performed spatial analysis"
- Good: "Conducted site suitability analysis that informed selection of 3 new facility locations, saving $200K in planning costs"

**Use CAR Method** (Challenge, Action, Result):
"Faced with inconsistent spatial data (Challenge), developed standardized QA/QC workflow using Python (Action), reducing data errors by 60% (Result)"

**Entry-Level Examples**:
```
GIS Intern
City Planning Department, Portland, OR
June 2025 - August 2025
• Digitized 500+ building footprints from aerial imagery to support zoning update project
• Created 20+ thematic maps for comprehensive plan using ArcGIS Pro
• Assisted senior planners with spatial analysis for development proposals
• Maintained geodatabase and performed quality control on spatial datasets
```

### Education Section

**Format**:
```
Degree, Major
University Name, Location
Graduation Date (or Expected Graduation)
GPA: X.XX (if 3.5 or higher)
Relevant Coursework: [list key GIS/tech courses]
```

**Recent Graduates**:
- Include relevant coursework
- Mention honors/awards
- Note relevant organizations

**Experienced Professionals**:
- Minimal detail needed
- Focus on degree and institution
- Remove GPA after few years

### Projects Section (Optional but Recommended for Entry-Level)

Include 2-3 relevant projects:
```
Urban Park Accessibility Analysis
• Analyzed park access for 50,000 residents using network analysis in ArcGIS Pro
• Created interactive web map displaying results using ArcGIS Online
• Identified 5 underserved neighborhoods for future park development
• Tools: ArcGIS Pro, Python, ArcGIS Online
```

### Certifications

List relevant certifications:
- GISP (GIS Professional)
- Esri Technical Certifications
- Project Management Professional (PMP)
- Programming certifications

## Tailoring Your Resume

### Reading the Job Description

**Identify**:
- Required vs. preferred qualifications
- Key skills mentioned multiple times
- Specific software or tools
- Domain knowledge needed
- Soft skills emphasized

### Customizing Your Resume

**For Each Application**:
1. **Adjust Professional Summary**: Align with specific role
2. **Reorder Skills**: Prioritize those mentioned in job posting
3. **Highlight Relevant Experience**: Emphasize applicable bullets
4. **Use Their Language**: Mirror terminology from job description
5. **Update Projects**: Feature most relevant work

**Example**:
If job emphasizes "Python automation for geoprocessing workflows," ensure your experience section highlights:
"Automated repetitive geoprocessing tasks using Python and ArcPy, reducing processing time from 4 hours to 20 minutes"

## Common Resume Mistakes

### Content Mistakes

1. **Too Generic**: Not tailored to position
2. **Typos/Errors**: Demonstrates carelessness
3. **Irrelevant Information**: Unrelated jobs or skills
4. **Missing Keywords**: Won't pass ATS (Applicant Tracking System)
5. **Vague Descriptions**: "Responsible for GIS" tells nothing
6. **Outdated Information**: Old address, outdated skills
7. **Personal Information**: Age, marital status, photo (in US)

### Formatting Mistakes

1. **Inconsistent Formatting**: Mixed fonts, spacing
2. **Hard to Read**: Too dense, tiny fonts
3. **Too Creative**: Unusual layouts that confuse ATS
4. **Multiple Pages for Entry-Level**: Keep to one page
5. **Tables/Columns**: May confuse ATS systems

### Strategic Mistakes

1. **Not Quantifying**: Missing numbers and metrics
2. **Passive Language**: "Was responsible for" vs. "Led"
3. **Listing Duties vs. Achievements**: What you did vs. what you accomplished
4. **Including Everything**: Quality over quantity
5. **Ignoring ATS**: Not optimized for scanning software

## ATS (Applicant Tracking System) Optimization

### What is ATS?

Software that scans and ranks resumes before human review. Many large organizations use ATS to manage high application volumes.

### ATS-Friendly Tips

1. **Use Standard Headings**: "Work Experience," "Education," "Skills"
2. **Include Keywords**: From job description
3. **Avoid Graphics/Images**: Stick to text
4. **Simple Formatting**: No tables, text boxes, headers/footers
5. **Standard Fonts**: Arial, Calibri, Times New Roman
6. **Save as .docx or PDF**: Check application instructions
7. **Spell Out Acronyms**: "Geographic Information Systems (GIS)"

## Cover Letters

### Purpose of Cover Letter

- Explain why you're interested in this specific position
- Highlight most relevant qualifications
- Show your personality and communication skills
- Connect your background to their needs
- Demonstrate knowledge of the organization

### Structure

**Paragraph 1: Introduction**
- Which position you're applying for
- Where you found the posting
- Brief statement of your qualifications
- Why you're interested

**Paragraph 2-3: Body**
- Highlight 2-3 most relevant qualifications
- Provide specific examples with results
- Connect your experience to their needs
- Show knowledge of organization

**Paragraph 4: Closing**
- Reiterate interest
- Thank them for consideration
- Call to action (look forward to discussing)
- Professional sign-off

### Length and Format

- **Length**: 3-4 paragraphs, half to three-quarters page
- **Format**: Business letter format
- **Tone**: Professional but personable
- **Customization**: Always tailored to specific position

### Example Opening Paragraph

"I am writing to apply for the GIS Analyst position at Metro Regional Planning, as advertised on your website. As a recent graduate with a B.S. in Geography and a concentration in GIS, combined with an internship at the City Planning Department, I am excited about the opportunity to contribute to Metro's transportation and land use planning initiatives."

### Example Body Paragraph

"During my internship with City Planning, I conducted spatial analysis to support the comprehensive plan update. Specifically, I analyzed park accessibility for 50,000 residents using network analysis, identifying underserved areas that informed the city's 10-year parks master plan. This experience, combined with my proficiency in ArcGIS Pro and Python, aligns well with Metro's need for data-driven analysis to support regional planning decisions."

### Cover Letter Tips

**Do**:
- Customize for each application
- Use specific examples
- Show enthusiasm
- Research the organization
- Proofread multiple times
- Use professional language
- Keep it concise

**Don't**:
- Repeat resume verbatim
- Use generic template language
- Exceed one page
- Focus solely on what they can do for you
- Include salary requirements (unless requested)
- Use overly casual language
- Send without proofreading

## References

### When to Provide

- Usually provided upon request, not with initial application
- Prepare list in advance
- Bring to interview

### Format

```
Name
Title
Organization
Phone Number
Email
Relationship to You
```

### Choosing References

**Good Choices**:
- Former supervisors
- Professors (for recent graduates)
- Internship coordinators
- Professional colleagues
- Clients (with permission)

**Poor Choices**:
- Family members
- Friends without professional connection
- People who don't know your work well

### Reference Etiquette

1. **Ask Permission**: Always ask before listing someone
2. **Provide Context**: Tell them about positions you're applying for
3. **Keep Updated**: Inform them when they might be contacted
4. **Say Thank You**: After they provide a reference
5. **Keep Information Current**: Update contact information regularly

## Application Materials Checklist

Before submitting:

- [ ] Resume tailored to position
- [ ] Cover letter customized for organization
- [ ] No typos or grammatical errors
- [ ] Consistent formatting throughout
- [ ] Contact information correct and professional
- [ ] Keywords from job description included
- [ ] Quantified achievements where possible
- [ ] Saved in requested format (.pdf, .docx)
- [ ] File names professional (FirstName_LastName_Resume.pdf)
- [ ] Portfolio link included (if relevant)
- [ ] References list prepared (if needed)

## Conclusion

Your resume and cover letter are marketing documents designed to get you an interview. They should be clear, concise, and compelling, highlighting your most relevant qualifications for each position. Invest time in crafting strong application materials, customize them for each opportunity, and continuously refine them as you gain experience. Remember: the goal is not to tell your complete professional story, but to generate enough interest to earn a conversation.
