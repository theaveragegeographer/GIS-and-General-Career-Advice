# Glossary of GIS Terms

## A

**Accuracy**: The degree to which data correctly represents real-world features or measurements.

**Address Geocoding**: The process of converting addresses into geographic coordinates.

**Aerial Photography**: Photographs taken from aircraft or drones for mapping purposes.

**Aspect**: The compass direction that a slope faces.

**Attribute**: Descriptive information about a geographic feature, stored in a table.

**Azimuth**: The horizontal angle measured clockwise from north.

## B

**Base Map**: A map layer that provides geographic context for other layers.

**Buffer**: A zone of specified distance around a geographic feature.

**Batch Processing**: Automated execution of multiple geoprocessing operations.

## C

**Cartography**: The art and science of map making.

**Choropleth Map**: A thematic map using color variations to represent data values.

**Coordinate System**: A reference system for locating features on Earth's surface.

**CRS (Coordinate Reference System)**: Defines how coordinates relate to positions on Earth.

## D

**DEM (Digital Elevation Model)**: Raster representation of terrain elevation.

**Digitizing**: Tracing features from imagery or maps to create digital data.

**Dissolve**: Combining adjacent features with the same attribute value.

**DTM (Digital Terrain Model)**: Similar to DEM, representing bare earth without vegetation.

## E

**ESRI**: Environmental Systems Research Institute, maker of ArcGIS software.

**ETL (Extract, Transform, Load)**: Process of moving data between systems.

**Extent**: The geographic area covered by a dataset or map.

## F

**Feature**: A geographic object with location and attributes (point, line, or polygon).

**Feature Class**: A collection of features with the same geometry type.

**Field**: A column in an attribute table.

**FOSS (Free and Open Source Software)**: Software that's freely available and modifiable.

## G

**GDAL (Geospatial Data Abstraction Library)**: Library for reading/writing raster and vector data.

**Geocoding**: Converting addresses or place names to coordinates.

**Geodatabase**: A database designed to store and manage geographic data.

**Geodesy**: The science of measuring and representing Earth's shape.

**Geoprocessing**: Operations that transform or analyze geographic data.

**Georeference**: Aligning imagery or data to real-world coordinates.

**GIS (Geographic Information System)**: System for capturing, storing, analyzing, and displaying spatial data.

**GISP (GIS Professional)**: Professional certification for GIS practitioners.

**GPS (Global Positioning System)**: Satellite-based navigation and positioning system.

**GNSS (Global Navigation Satellite System)**: Generic term for all satellite navigation systems.

## H

**Heatmap**: Visualization showing intensity or density of phenomena.

**Hot Spot Analysis**: Statistical method to identify spatial clusters.

## I

**Imagery**: Photos or digital images of Earth's surface from satellites or aircraft.

**Interpolation**: Estimating values at unsampled locations based on nearby samples.

**Intersection**: Spatial operation that finds overlapping areas between features.

## J

**Join**: Combining attribute data from two tables based on common field.

## K

**KML (Keyhole Markup Language)**: XML-based format for geographic data, used by Google Earth.

## L

**Layer**: A collection of similar geographic features displayed on a map.

**LiDAR (Light Detection and Ranging)**: Remote sensing technology using laser pulses.

**Line**: A feature composed of connected vertices forming a path.

## M

**Map Projection**: Mathematical transformation of Earth's curved surface onto a flat map.

**Metadata**: Data about data; descriptive information about a dataset.

**Model Builder**: Visual programming tool for creating geoprocessing workflows.

**Mosaic**: Combining multiple images or rasters into a single seamless dataset.

**Multiband Raster**: Raster with multiple layers, each representing different information.

## N

**NDVI (Normalized Difference Vegetation Index)**: Measure of vegetation health from imagery.

**Network Analysis**: Analysis of connected linear features like roads or streams.

**North Arrow**: Map element indicating direction of north.

## O

**OpenStreetMap (OSM)**: Collaborative open-source mapping project.

**Overlay**: Placing one map layer on top of another for analysis.

## P

**Pixel**: Smallest unit of a raster image.

**Point**: A feature representing a single location.

**Polygon**: A closed feature with an interior area.

**PostGIS**: Spatial extension for PostgreSQL database.

**Precision**: The level of detail in measurements; number of decimal places.

**Projection**: See Map Projection.

**Python**: Popular programming language for GIS automation and analysis.

## Q

**QGIS**: Popular free and open-source desktop GIS software.

**Query**: A request for data meeting specific criteria.

## R

**Raster**: Data model representing features as grid of cells (pixels).

**Remote Sensing**: Collecting information about Earth from aircraft or satellites.

**Resolution**: The level of detail in raster data; size of pixels.

## S

**Scale**: Ratio between distance on map and distance on ground.

**Scale Bar**: Map element showing relationship between map distance and real distance.

**Shapefile**: Common vector data format developed by Esri.

**Slope**: Steepness of terrain, usually measured in degrees or percent.

**Spatial Analysis**: Examining relationships, patterns, and trends in geographic data.

**Spatial Join**: Combining data from two layers based on spatial relationship.

**SQL (Structured Query Language)**: Language for querying databases.

**Symbology**: Visual representation of features on a map (colors, symbols, etc.).

## T

**Tile**: Small image segment used in web mapping for efficient display.

**Topology**: Spatial relationships between features (connectivity, adjacency, containment).

**TIN (Triangulated Irregular Network)**: Vector representation of surfaces using triangles.

## U

**Union**: Spatial operation combining all features from two layers.

**UTM (Universal Transverse Mercator)**: Common coordinate system dividing Earth into zones.

## V

**Vector**: Data model representing features as points, lines, or polygons.

**Vertex**: A point defining part of a line or polygon boundary.

**Viewshed**: Area visible from a specific location.

## W

**WCS (Web Coverage Service)**: Standard for serving raster data over the web.

**WFS (Web Feature Service)**: Standard for serving vector data over the web.

**WGS84 (World Geodetic System 1984)**: Global coordinate system used by GPS.

**WMS (Web Map Service)**: Standard for serving map images over the web.

## X

**XML (eXtensible Markup Language)**: Text-based format for storing and transporting data.

## Z

**Z-value**: Elevation or vertical coordinate value.

**Zoom**: Changing map scale to see more or less detail.
